# Security

PlotBench is a desktop program. Project files (`.pbp`) and formulas from other people are treated as data: formulas only allow
arithmetic and a fixed list of functions, and project files are checked and size-limited before anything is opened. The Python
console and "Run Python script" run code by design; only run scripts you trust.

**Supported version:** the latest release only.

**Reporting a problem:** please e-mail Kishan Tiwari (kishantiwari@iitkgp.ac.in) instead of opening a public issue, with the version,
your operating system and the steps or file that show the problem. You should get a reply within two weeks.

The installers are not code-signed. Download them only from https://github.com/kishangeo/PlotBench/releases and compare them with the
SHA-256 checksums shown there.
